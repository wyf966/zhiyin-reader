# 导入、认证与阅读统计修复计划

**目标：**修复本次报告的九项问题，保留已有数据和工作区改动，不新增依赖。

**实现：**沿用前端解析、服务端存储的边界。图片缓存改用服务器、读者、文档、图片联合键，旧缓存弃用并从原 EPUB 恢复；正文和图片内容共同参与 EPUB 去重。认证只在明确拒绝令牌时清理。统计接收读者 IANA 时区，最近阅读按最新进度排序。

## 执行顺序

- [x] 认证：网络、超时、503 保留令牌，401 清理；恢复网络自动恢复会话。
- [x] 默认端口恢复 3000；Markdown 同段重复图、引用图和表格内容保留。
- [x] 图片持久缓存和内存 URL 全面隔离；安全丢弃旧缓存，从原文件恢复服务端错图。
- [x] EPUB 图片摘要参与新哈希；旧哈希通过原文件重新解析后升级，不能仅凭旧正文哈希拒绝新插图。
- [x] 原文件上传等待结果，失败明确回执并支持补传。
- [x] 阅读时长按 IANA 时区切日周（包括夏令时）；最近阅读以跨设备最新记录排序。

- [x] 执行两端类型检查、构建、单元测试、接口测试和真实浏览器回归。

## 回归重点

同路径不同图的两本 EPUB 及服务端二进制；旧缓存迁移后原文件恢复；刷新成功但取读者资料失败；原文件丢失时给出重新选择入口；旧哈希升级后同书重复与仅改插图；北京周一早晨与夏令时；分页排序稳定。

## 数据兼容与限制

旧图片缓存因缺少可信归属而重建；其他缓存和离线队列保留。已保存原 EPUB 的书在显示图片时可恢复并覆盖服务端错图。原文件缺失时无法自动判断旧图片是否正确，会提示读者重新选择；旧书去重同样不能只凭旧正文/路径摘要拒绝导入，此时允许新增书籍。表格按文本行保留，不引入新的表格段落类型。
